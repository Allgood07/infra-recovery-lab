# Infra Recovery Lab

Раньше `Allgood07/test` был тестовым репозиторием. На момент начала работы над Lab переименованный репозиторий не содержал коммитов. Лаборатория начинается с этого стенда, а не с даты создания репозитория.

## Локальная проверка

Нужны `make`, Python 3.11+, OpenTofu 1.9+ и запущенный Docker Engine с CLI (на macOS подойдёт Docker Desktop). Выберите локальный Docker-контекст с Unix-сокетом; не используйте прокси к удалённому Docker. Для первой загрузки образа и провайдера нужен интернет.

| Команда | Том при замене | Ожидаемый результат |
| --- | --- | --- |
| `make verify` | Исходный | `PONG`, `GET` вернул точный маркер; выход `0`. |
| `make wrong-volume` | Новый пустой | `PONG`, `GET` того же ключа сообщает об отсутствии ключа (`GET=KEY_MISSING`); ненулевой выход. |

Каждый запуск начинает с нуля, создаёт внутреннюю сеть, исходный именованный том, Valkey и отдельный клиент без опубликованных портов. Проверка подтверждает запись в режиме AOF с `appendfsync always`, удаляет только контейнер Valkey и проверяет недоступность его старого адреса. OpenTofu применяет проверенный сохранённый план: в штатном режиме — только создание Valkey, в контроле — создание Valkey и нового тома. Исходный том остаётся на месте до очистки.

В обоих прогонах на новом соединении проверка требует `PONG` и точный прежний маркер, без повторной записи. Готовность и чтение имеют общий дедлайн 30 с с момента запуска замены. Это не SLA и не проверка потери диска или хоста. Контроль подтверждён, только если есть `PONG`, `GET=KEY_MISSING`, сообщение `Cleanup OK` и ненулевой выход. Ошибка запуска, таймаут, другое значение и зелёный контроль не подтверждают результат.

Офлайн-проверки: `python3 -B -m unittest -v test_verify`.

При выходе удаляются только ресурсы прогона. Локальный state удаляется после проверки, что клиент, Valkey, сеть и все тома прогона отсутствуют. Если очистку не удалось подтвердить, команда завершается с ошибкой и сохраняет `.runs/<ID>/` для разбора. Образ остаётся в кеше Docker, провайдер — в `.runs/` отдельно от состояния прогона.
